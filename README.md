# doctor-shapovalov-feeds

Автогенерация товарных фидов услуг пластического хирурга Шаповалова
([doctor-shapovalov.ru](https://doctor-shapovalov.ru/)) для рекламных кабинетов:

- **Яндекс.Вебмастер** «Товары и цены» (+ Яндекс.Услуги, товарный поиск) — YML
- **VK Реклама** → Товарный каталог (динамический ретаргет) — тот же YML (VK поддерживает формат YML)
- Годится и как фид для Яндекс.Директа (умные баннеры)

Публичный URL фида (после включения Pages):
**https://ernest-koz.github.io/doctor-shapovalov-feeds/feed.yml**

## Как это работает

```
services.yaml  (источник правды — правится руками: цены, описания)
      │  python generator.py
      ▼
docs/feed.yml + docs/index.html   (GitHub Pages раздаёт статику из /docs)
      ▲
      └── GitHub Actions (.github/workflows/generate.yml):
          - при изменении services.yaml / generator.py
          - и ежедневно в 03:30 UTC (обновляет дату фида — Яндекс не любит несвежие)
```

## Правки цен

1. Открыть `services.yaml`, поменять `price_from:` у услуги.
2. Закоммитить/запушить — Actions пересоберёт фид через ~1 минуту.
3. `price_from: null` → услуга исключается из фида и попадает в «Ждут цены» на index-странице.

⚠️ Текущие цены сняты со снапшота сайта от 12.10.2026. Цены правились 26–27.10 —
**перед подключением кабинетов сверить с актуальным прайсом врача** (7 услуг без цены ждут подтверждения — см. index.html).

## Первичная настройка (один раз)

1. **Включить Pages:** Settings → Pages → Source: «Deploy from a branch», Branch: `main`, Folder: `/docs` → Save.
2. Проверить: `https://ernest-koz.github.io/doctor-shapovalov-feeds/` (index) и `.../feed.yml`.
3. **Яндекс.Вебмастер:** раздел «Товары и цены» → добавить фид по URL → дождаться загрузки → проверить статистику.
4. **VK Реклама:** Кабинет → Каталоги → «Создать каталог» → «По ссылке» → вставить URL `feed.yml` → выбрать тип YML → после загрузки создать кампанию динамического ретаргета на сегмент посетителей сайта.
5. **Предусловие VK:** пиксель VK должен быть установлен на сайт (без него события не собираются и ретаргету не на кого смотреть).

## Локальная генерация (для проверки)

```bash
python generator.py   # только stdlib, без зависимостей
```

## Медицинские нюансы модерации

- Я.Вебмастер/Услуги и VK проверяют мед. тематику: если попросят — приложить лицензию/аккредитацию
  (номер аккредитации: 7823 030963013).
- Дисклеймер «ИМЕЮТСЯ ПРОТИВОПОКАЗАНИЯ…» включён в index-страницу; в офферы не пишется (необязателен в YML).
- Цены в фиде = «от», на страницах услуг — актуальные условия и рассрочка.
